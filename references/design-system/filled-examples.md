# 完整填参示例

以下8个示例是本次编写的迁移示例，不是采集到的案例，也没有执行生图。最后一个演示预设结构替换。

## 咖啡店阅读月

T01 / T01-1 · 大字是场景的墙，微小行动提供尺度；静止水平面被一条斜线打破。

```text
制作3:4的海报，表达咖啡店阅读月。上部保持浅色空场，中部用“慢读”形成宽扁厚重的字墙，下部安置一名虚构成年读者正在坐在临水小台面上安静读书，主体相对字墙很小。用清楚的水平面承托行动，再由从书页伸向右下方的细长书签形成一条细长斜线连接两层。主色深蓝静水色承载场景，深色深墨色承载信息，小面积读者手中书封的暖橙色点亮行动焦点。吸墨纸、局部网点、轻微掉墨只出现在字块、承托面及其边缘，空场保持干净。文字层级为大标题、短说明、页脚；仅出现提供的标题；不生成英文、日期、价格、署名、标志或其他文字。保留大字、微小叙事和静面之间的尺度反差。
避免：不要把主体放大成普通主角海报；不要让细线成为多条装饰线；不要平均分配字与图的重量。
```

检查：核心短词占据中部主要宽度；叙事焦点明显小于字形；水平承托面与单条斜向线共存；只出现输入允许的文字与事实。

## 谷雨新茶概念

T03 / T03-1 · 两侧巨大色域夹出中央通道，通道尽头的微小焦点表现希望。

```text
制作3:4的海报，主题谷雨与新芽的清润生长。两侧以高明度浅绿刷色的巨大有机刷色块压近中央，顶部及外缘出血；中央留出略有曲折、向下扩开的近白通道。在通道底端放置微小的一枚带细梗的微小嫩芽正在在中央明亮通道的下端展开，用尺度差制造深远空间。标题“谷雨”拆成少量大字分置上缘两端；短说明沿通道排成疏朗窄列，一笔一笔清亮朱橙色手写线横穿窄列但不阻塞通道。块面呈水粉平涂、干刷纵痕、微弱纸纤维，纹理集中在色块边缘。仅出现提供的标题；不生成英文、日期、价格、署名、标志或其他文字。
避免：不要把通道填满文字；不要把微小焦点放大；不要让两侧变成写实背景墙。
```

检查：两侧大块面主导画面；中央狭长明亮通道由上贯穿到下；微小焦点位于通道下端；只出现输入允许的文字与事实。

## 虚构人物棚拍

T09 / T09-1 · 一主一辅的柔光塑造骨相，动作支撑与皮肤细节决定可信度。

```text
制作4:5的棚拍肖像。人物为一位虚构成年创作者，不对应真实个人，人物为虚构，按上述设定生成，不宣称与真实个人一致。头肩至胸部构图、眼平视角、短长焦透视；人物正在双手自然托住无标识机械相机，目光专注前方，双手与道具的抓握和支撑准确。左前上方大柔光源，右侧更弱回填，眼神光与主光同向塑造清楚但柔和的面部过渡，背景为低对比冷中性灰背景，服装哑光黑色服装与背景靠明度分离。妆发适配本人，不改变骨相；保留毛孔、细发和哑光西装、自然皮肤、灰底的真实纹理。情绪专注、克制用目光、呼吸与嘴角变化表现。完全无文字，无刊头、无标志、无水印。
避免：避免身份漂移、塑料皮肤、僵硬手指、无支撑道具和矛盾眼神光；镜头描述是视觉意图而非真实拍摄元数据。
```

检查：身份特征稳定；主光方向明确；手与道具具有可信支撑；只出现输入允许的文字与事实。

## 可颂产品上新

T12 / T12-1 · 放大可食用的断面与真实触感，信息退到留白而不覆盖食物。

```text
制作3:4的海报，产品原味可颂，仅含已提供产品外形，主题原味可颂上新。将产品放大到中部主要宽度，采用从侧上方展示一处自然断口的近摄角度，清楚呈现真实酥皮薄层与少量自然碎屑所指的真实层次；表面依据柔软乳脂层、真实水果切面、清洁高光呈现，不新增未提供的食材。左上方柔和漫射光均匀包裹主体，阴影浅且靠近接触面。上方暖白高明度净色保留呼吸空间，标题“新鲜出炉”细长克制，底部以小标签承载。主体自然色自然金棕色提供主要色彩，小面积深暖棕信息色仅做小面积信息强调。仅出现提供的标题；不生成英文、日期、价格、署名、标志或其他文字。
避免：不要塑料食物、夸大馅料或虚构营养功效；不要厚重道具背景；价格只能使用提供的值。
```

检查：食品占据中段视觉重量；符合真实成分的质地与断面；阴影浅而具有接触感；只出现输入允许的文字与事实。

## 教学知识卡

T23 / T23-1 · 每组图形只解释一个命题，图与文的换位节拍代替装饰密度。

```text
制作3:4的教学知识卡，主题阅读笔记的三步整理，内容仅来自01 选摘录：只记录与问题相关的原句；02 写理解：用自己的话解释；03 建连接：关联已有笔记。仅有这三条输入内容。。先整理为三组以内的主结论，每组包括短标题、必要说明与一幅解释性书页、摘录卡和知识连接的单线示意图。内容模块纵向排列，图与文字左右交替，连接三组内容的轻柔阅读曲线的柔曲线只用于模块分隔与阅读牵引。暖白高明度净色为安静浅底，白色内容岛保持宽内边距，深墨色用于线描与正文，一处小面积暖色仅负责序号。图像呈朴拙单线、柔曲线白岛、少量黑填，信息短句化；标题“把阅读变成笔记”准确，数字和因果不增补。标题与三条步骤文字必须准确，正文若难以清晰呈现则改为无字底图并后续排版；不加入新步骤和统计数据。
避免：不要无来源统计、研究结论或营养功效；不要靠很小字号塞入长文；信息过多先拆张。
```

检查：每模块只有一条主结论；插图解释对应内容；编号和文字层级贯穿全图；只出现输入允许的文字与事实。

## 品牌汇报目录

T22 / T22-1 · 标题与数据先建立信息层级，图形按页的叙事功能进入共同网格。

```text
设计16:9的演示目录页，主题品牌设计方案目录，受众会议投影观看者，页面内容来自仅四项目录：品牌定位、视觉系统、应用场景、执行计划。没有数值或图表数据。。在统一边距与基线网格上，标题“品牌设计方案”优先，关键结论次之，证据和细节最后；依据当前页目的选择双栏、跨栏或稀疏模块，而非每页同版式。背景暖白高明度净色、承托低饱和主题色、强调一处小面积暖色按面积分工，文字深墨色保持清晰反差。一块跨栏浅色矩形作为一处跨栏视觉锚点，工艺哑光浅色模块、轻接触阴影、扁平细图形不可侵入正文。正文和图表轴线整齐；所有数值、单位、标签逐字来自输入。准确呈现标题和四项目录；没有其他文字、图表数据或随机页码，细字不清晰时后续排版。
避免：不要把7:2:1面积比例写成明度比例；不要幻造数据或用装饰图代替证据；复杂图表应转为可编辑排版。
```

检查：固定边距、基线与文字层级；版式依据内容量变化；数据数值与标注来自输入；只出现输入允许的文字与事实。

## 城市日签无事实补造

T24 / T24-1 · 日期是锚点，实体照片是核心，一道问候跨过照片和纸面。

```text
制作3:4的日签风格海报，主题虚构海滨城市晨间问候。将不对应真实地标的海滨步道中的虚构海滨步道与清晨行人化为主要纪实照片，带宽白纸边或两块错位低饱和衬纸，置于暖白高明度净色暖亮纸面。日期、星期与地点按未提供日期、星期、天气和具体城市名，全部省略准确排布，缺失则省略。标题“早安”以细衬线或可辨认手写笔触跨过照片一角与纸面，底部寄语留一点时间，看看身边。只保留短句。照片内为左侧晨光，纸面为同方向柔和光线让照片内的空间自然，纸边与胶带有浅接触阴影，浅海蓝自然影像来自照片，仅用灰蓝衬纸作一处衬纸回声。只出现“早安”和“留一点时间，看看身边。”；其余文字一律不生成。
避免：不要猜测日期、星期、天气或名言出处；不要用装饰性随机文本；纸纹只出现在纸面。
```

检查：日期、照片、寄语三层清楚；照片具有实体纸边或错位衬纸；最短问候横跨照片边界；只出现输入允许的文字与事实。

## 三周年纪念数字空间

T16 / T16-2 · 数字作为可进入空间，而不是普通平面标题

```text
制作3:4品牌三周年纪念概念海报。中央是一面暖米白哑光墙，深凹的数字3开口占据主要视觉重量；数字轮廓完整，内壁有厚度与浅接触阴影。凹槽里填入大小不同的深灰蓝柔哑圆体与少量同色细碎装饰，沿数字内部排列。一位虚构成年访客自然坐在数字下沿，一部分身体伸出开口，手臂与腿具有真实支撑，保持人物相对数字很小。左上方柔暖斜光塑造内凹与接触关系，极少柔金色仅用于点缀。上方保留宽留白，只用疏朗细衬线呈现“三周年”。没有页脚、品牌标志或其他文字。整体正面视角、轴线稳定、温柔而安静。
避免：不要多组微型人物活动，不要平面印刷数字，不要漂浮装饰或虚构品牌标志。
```

检查：巨型数字为真实深凹开口；填充物沿数字轮廓组织；人物具有支撑并跨过边界；只出现三周年文字。
