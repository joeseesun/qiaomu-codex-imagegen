# 描述怎么写

工具会把「内容描述 + 风格 + 格式规则 + 文字规则」组装成最终提示词（`build_prompt` 可以先看）。你只负责写**内容描述**。

## 好描述的四件事

1. **一个主体、一个视觉重心。** 先把主题压缩成一个象征物和一种空间关系，而不是罗列元素。
   - 差：「一本书、咖啡、窗户、植物、猫、阳光」
   - 好：「窗边的一本翻开的书，书页上升起一杯咖啡的热气，形成一座小山的轮廓」
2. **空间关系比形容词有用。** 大小对比（很小的人 + 很大的物体）、位置（占下方 20%）、留白（上方 70% 留空）。
3. **情绪用一个词。** 敬畏、孤独、危险、安静，选一个。
4. **人物用剪影、背影、手或象征物**，除非用户要真实面孔。

## 不要写进描述的

- 风格词（水彩、丝网印）→ 用 `style`。
- 比例和尺寸 → 用 `preset` 或 `aspect_ratio`。
- 「不要文字」→ 默认已经加了；要文字用 `text`。

## 文字政策

模型写中文和长句容易出错。优先：图里不放字，后期排版。必须图内文字时：短（≤ 8 字）、逐字给出、生成后放大检查。

## 迭代

- 一次只改一个变量（描述、风格、比例之一），否则不知道是什么起了作用。
- 要选择时用 `count` 2–3，不要连续单张重试（每次都消耗额度）。
- 有满意的一张后，用它做 `reference_images` 保持系列统一，或做局部修改。
- 工具返回的 `Revised prompt` 是模型实际使用的版本，可以拿来看哪里被改写了。
